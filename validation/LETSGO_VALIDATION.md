# letsgo 离线验收记录

本文件记录上位机适配验证，不代表已经通过实机运动验收。

## 验证范围

- 原始字节协议、CRC8 标准向量、碎片帧/粘包/坏校验恢复。
- 电控模式—动作组合，禁止上位机发送初始化和无效组合。
- 默认禁用运动，显式允许后下发；重复请求不重复执行。
- 等待模式反馈后发送跳跃，按配置时长加余量保护，暂停时不立即用站立打断跳跃。
- 状态、定位、控制器心跳超时以及故障/z/重新踩点锁定暂停。
- 串口短写不重放动作，模式确认超时不继续动作。
- 身后目标不误判到达，两目标顺序推进，障碍路线完成后不越界。
- 第三级台阶使用普通模式6，两次有效踩点前不输出任务坐标。
- 真实 ROS 节点、话题与服务经 Linux PTY 虚拟 TTL 完成允许、两点导航、站立、暂停联调。

当前测试：21 项通过。使用 ROS_DOMAIN_ID=184、ROS_LOCALHOST_ONLY=1，未向实物发送任何指令。
