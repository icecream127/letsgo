# 实机地图

当前 `bash run/gicp.sh` 默认加载 `real_room_20261121_112353_068513.pcd`。
地图随仓库分发；旧的 2026-09-26 地图保留，不覆盖。

小电脑继续使用尾号 11 的 MID-360：`mid360_real.json` 中雷达 IP 保持
`192.168.1.111`，电脑地址保持 `192.168.1.50`。地图文件不绑定雷达序列号，
但实际环境必须与地图对应，安装方向和 LiDAR–IMU 参数必须正确。

更新仓库后从项目根目录运行 `bash run/gicp.sh`，无需为地图重新编译。
若此前导出了 `GICP_MAP_PATH`，先 `unset GICP_MAP_PATH` 才会使用默认新图。
新图需要重新给初始位姿；用于走点时重新采 A/B，不能直接沿用旧地图坐标。

切换其他地图仍可使用 `GICP_MAP_PATH=/绝对路径/地图.pcd bash run/gicp.sh`。
